# 🚗 Elite Autos

A luxury car dealership web application. Customers can browse vehicles and send inquiries, while the admin manages inventory and customer messages from a dashboard.

> **Note:** This is a demo / portfolio project. All company details (address, phone, email) are sample data.

🔗 **Live demo:** https://anuththara599.github.io/elite-autos/

---

## ✨ Features

### 👤 Customers
- Browse the full vehicle inventory
- Filter by body type: Sedan, SUV, Sports
- View detailed specifications for each vehicle
- Register and log in securely
- Send inquiries to the seller about a vehicle
- Contact form with validation
- About and Concierge (contact) pages

### 🏪 Admin / Seller
- Role-based access to the Management Console
- Add new vehicles to the inventory
- Edit vehicle details, price and status (In Stock / Sold)
- Delete vehicles (with confirmation)
- View customer inquiries and contact requests
- Reset demo data

## 🛠 Built With

- HTML5
- CSS3 (responsive black & gold design)
- JavaScript (single-page app with hash routing)
- Browser `localStorage` as the data store

The project was originally designed with **PHP + MySQL** and was converted into a single-file front-end app so it can run without a server.

---

## 🚀 Run Locally

1. Download `index.html`
2. Double-click it to open in your browser

No installation or server required.

---

## 🛡 Security Notes

- Passwords are hashed before being stored
- All displayed data is escaped to prevent XSS
- Admin pages are protected by role checks

> Because data is stored in the browser, it is local to each visitor's device. A production version would use a real backend (PHP + MySQL).
